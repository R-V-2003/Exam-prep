# GovPrep AI (Exam-prep)

A comprehensive exam preparation application built as a modern Progressive Web App (PWA) and packaged for Android using Capacitor.

## 🚀 Deployment
- **Web App:** To be deployed soon.
- **Android APK:** You can download the latest Android `.apk` from the [Portfolio Downloads](https://r-v-2003.github.io/RAHUL_MALI_PORTFOLIO.github.io/) page!

## 🛠️ Tech Stack
- **Frameworks:** React/Vite
- **Mobile Container:** Ionic Capacitor
- **Backend:** Supabase & Firebase
- **Styling:** CSS / Tailwind (presumably)

## ✨ Features
- Cross-platform exam preparation modules.
- Analytics and dashboard to track your misery, I mean progress.
- Seamless authentication and progress syncing.

## 🛠️ Development Setup
```bash
npm install
npm run dev
# To build for Android
npm run build
npx cap sync android
```
